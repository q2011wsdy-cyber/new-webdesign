Design system / token viewer

一个能被直接看见的设计系统。

此页面直接读取全站 Token。修改 styles/design-tokens.css 后刷新，即可同时检查颜色、排版、空间、形状、动效和组件表现。

01 / COLORS

语义色彩

颜色按用途命名，而不是按色值命名。点击任意 Token 可复制当前主题中的计算值。

02 / TYPE

字体层级

全站使用 JetBrains Mono，并以标签、说明、正文、品牌和标题组成基础层级。

03 / SPACING

正在使用的空间尺度

这里只展示已经接入首页或案例页的间距 Token。

04 / SHAPE

正在使用的圆角

当前展示作品卡片和顶栏胶囊已经接入的圆角 Token。

05 / MOTION

正在使用的动效 Token

展示全站主题过渡、控件反馈和页面平滑滚动实际读取的参数。

06 / COMPONENTS

现有组件

只展示网站中已经上线的主页双按钮与案例页三按钮液态控件。
