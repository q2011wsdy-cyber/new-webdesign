# PRD｜Super Lee Portfolio

> 当前版本：v1.0  
> 产品类型：个人产品设计作品集  
> 文档状态：当前实现基线

## 1. 背景与目标

网站用于集中展示 Super Lee 的产品设计案例。它需要在保持个人视觉风格的同时，让访问者能快速定位作品、进入项目详情、理解设计过程，并在不同语言与主题下保持体验一致。

### 成功标准

- 访问者能从首页直接进入已发布案例。
- 每个已发布案例均有标题、副标题与封面，并可自由编排详情内容。
- 语言与主题切换在首页、案例页间保持一致。
- 案例图片在不同屏幕尺寸下不失真、不被意外裁切。
- 后续添加案例无需复制整套页面布局逻辑。

## 4. 非功能需求

- 静态可部署：无需后端或构建服务即可由静态文件服务器运行。
- 资源本地化：React、Babel、Lottie 播放器与案例素材均随仓库保存，避免关键页面依赖外部运行时。
- 缓存可控：页面加载共享脚本时使用版本查询参数；改动后需更新版本号。
- 可访问性：图片保留有意义的 `alt`；支持减少动态偏好。
- 性能：新增图片前检查文件体积；大于约 1 MB 的图片优先考虑压缩为 WebP 或优化 PNG。
